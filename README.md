
# Sample Fullstack Project

Technologies:
- React Frontend
- Node.js Backend
- MongoDB Atlas
- GitHub
- Vercel
- Render

## Run Frontend

cd frontend
npm install
npm run dev

## Run Backend

cd backend
npm install
npm run dev

## MongoDB

Update backend/.env with your MongoDB Atlas connection string.

## Deployment

Frontend -> Vercel
Backend -> Render
Database -> MongoDB Atlas
